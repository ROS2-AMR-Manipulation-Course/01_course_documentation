# Prerequisites

## 1. Required Knowledge

Students should have basic knowledge of:

### Linux

* Basic terminal commands
* File and directory management
* Installing software packages
* Running shell commands
* Basic environment variables

### Programming

Students should have basic programming experience, preferably with:

* Python
* C/C++ fundamentals
* Functions
* Variables
* Classes and objects
* Basic debugging

### Mathematics

Students should understand basic:

* Algebra
* Trigonometry
* Coordinate systems
* Vectors
* Matrices

Advanced mathematics is not required before starting the course. Kinematics concepts will be introduced progressively during the course.

### Robotics

Basic knowledge of robotics is helpful but not required.

Students should be familiar with simple concepts such as:

* Robot
* Sensor
* Actuator
* Motor
* Coordinate frame

## 2. Required Computer Skills

Students should be able to:

* Use a Linux terminal.
* Create and edit files.
* Install packages.
* Clone a Git repository.
* Use basic Git commands.
* Navigate a project directory.
* Read configuration files.

## 3. Recommended Git Knowledge

Students should understand basic Git operations:

```bash
git clone
git status
git add
git commit
git push
git pull
```

## 4. Recommended Preparation

Before the course starts, students should prepare:

* Ubuntu 24.04 LTS
* A working internet connection
* A GitHub account
* Git
* A code editor such as VS Code
* Basic Python knowledge

The official ROS 2 and Gazebo environment will be installed according to the course setup instructions.

## 5. What Students Do Not Need Before the Course

Students do not need previous experience with:

* ROS 1
* ROS 2
* Gazebo
* Nav2
* SLAM Toolbox
* MoveIt 2
* Industrial robot programming

These technologies will be introduced during the course.

## 6. Important Recommendation

Students should complete the software installation and environment verification before beginning the Week 1 laboratory.

A working development environment is important because later laboratories depend on the same ROS 2 environment.
