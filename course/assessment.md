# Assessment

## 1. Assessment Philosophy

Assessment is based on both theoretical understanding and practical robotics skills.

Students are expected to demonstrate that they can:

* Explain robotics concepts.
* Implement ROS 2 systems.
* Run simulations.
* Debug problems.
* Analyze robot behavior.
* Complete laboratory tasks.
* Document their work.

## 2. Assessment Components

The course assessment consists of:

| Component                      |   Weight |
| ------------------------------ | -------: |
| Weekly Laboratory Work         |      30% |
| Weekly Exercises / Assignments |      20% |
| Practical Demonstrations       |      20% |
| Final Project                  |      30% |
| **Total**                      | **100%** |

## 3. Weekly Laboratory Work — 30%

Students complete practical laboratory tasks each week.

Assessment considers:

* Task completion
* Correct ROS 2 implementation
* System operation
* Debugging
* Understanding of the implementation
* Documentation

## 4. Weekly Exercises / Assignments — 20%

Students complete short exercises related to the weekly lecture.

Examples:

* ROS 2 communication exercises
* TF2 analysis
* Kinematics calculations
* SLAM analysis
* Navigation configuration
* Manipulator kinematics

## 5. Practical Demonstrations — 20%

Students demonstrate their systems during practical sessions.

Examples:

### Week 1

Demonstrate ROS 2 node communication.

### Week 2

Demonstrate Trailobot simulation.

### Week 3

Demonstrate mapping and autonomous navigation.

### Week 4

Demonstrate manipulator motion planning.

## 6. Final Project — 30%

Students complete an integrated robotics project.

The project should demonstrate the student's ability to combine concepts learned throughout the course.

Assessment includes:

* System design
* ROS 2 implementation
* Robot modeling
* Simulation
* Navigation and/or manipulation
* System integration
* Testing
* Documentation
* Presentation

## 7. Submission Requirements

Students should submit:

* Source code
* Configuration files
* Launch files
* Documentation
* Demonstration video where required
* Final report
* GitHub repository

## 8. Academic Expectations

Students should:

* Write their own code.
* Understand code that they submit.
* Properly reference external resources.
* Document modifications to existing open-source projects.
* Avoid submitting copied work without understanding it.

Using open-source ROS 2 packages is allowed when permitted by the assignment, but students should understand how the packages are used and configured.
