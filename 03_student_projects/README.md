# Student Projects

**Navigation:** [Repository README](../README.md) · **Student Projects** · [Requirements](project_requirements.md) · [Submission Guide](submission_guide.md) · [Rubric](project_rubric.md)

The final project brings together everything from the four course weeks into one working, documented, and measured ROS 2 system. It counts for **30%** of the course grade ([assessment policy](../01_course_documentation/course/assessment_policy.md)).

## Timeline

| When                 | Milestone                                                  |
| -------------------- | ---------------------------------------------------------- |
| Week 2               | Choose a track; confirm the robot platform                 |
| Week 3               | Architecture diagram and success criteria agreed with the instructor |
| Week 4               | Integration and evaluation                                 |
| After Week 4         | Submission and presentation (dates announced by the instructor) |

| Week | Lab output you can reuse                                          |
